# enhanced-shortcuts
Making some shortcuts I feel would be nice to have on browsers
I'll add more as I get ideas

__Shortcut 1: Copy Current URL__
Copies the URL of the page that is currently focused by pressing Alt+Shift+D, or Option+Shift+D on Macs.

Got the idea for this from arc which I used for a bit, so credits to the browser company for the idea.

__Shortcut 2: Send Current Tab To New Window__
Whatever tab is currently focused goes to a new window by pressing Alt+W, or Option+W on Macs. 

I was doing this manually way too much when looking through lecture slides so I figured it'd be nice to have it as a shortcut.

__Shortcut 3: Duplicate Current Tab__
Duplicates the current tab in the same window by pressing Alt+K or Option+W on Macs.

Edge has this shortcut already but I don't think chrome does so I figured might as well add it since it's relatively useful.
